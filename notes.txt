### Creating Git config
1. We need to set the user name

    git config --global user.name "ponraj73"

2. We need to set the email id 

    git config --global user.email "emailid@gmail.com"

3. we need to set the default branch name "main"

    git config --global init.defaultBranch main

### go to the previous files
this command is used when we need to go to the previos versions like 2 years back or 22 days back like that...

    git checkout < commit id >  -> after doing this we go to that commit and the files present in that commit will show and other files wont show....

    git checkout main           -> By this we come to our present version so all the files adn folders are present here

    git checkout -f main        -> this is a force checkout that discard all the changes on the files adn come back to the main

### Branch

the branch is nothing but a copy of a main branch and used to modify the copies....because our main branch is workng fine...if we change some data and there might be affect the working condition of the mainbanch
so for this we keep the working things on the main branch and keep the develop things on a devlop or any other branch...

    git branch < Branch name >      -> this creates a branch
    if we need to go to that branch we need to checkout

    git checkout -b < Branch name > -> this directky creates a branch and checkout automativally to that branch

### push the code to the remote repo

for this we need to use the upstream
    git push --set-upstream origin < branch name >

    or 

    git push -u origin < branch  name >
so after doing this our changes are pushed to the remote and repo...and then we need to do the compare & merge
after doing this we can use just
    git push

### Pull
so after merging the changes those are wont appear on the local main...so we need to do git Pull

    git pull 

this will download all the files adn folders with the latest changes
